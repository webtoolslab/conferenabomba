# Confere na Bomba - pacote PWA

Este pacote prepara o site para instalação como aplicativo (PWA).

## Atualização no GitHub
Substitua os arquivos existentes no repositório `webtoolslab/confere-na-bomba` pelos arquivos deste pacote e faça Commit changes:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Mantenha o repositório GitHub Pages publicado em HTTPS.

## Instalar no iPhone
1. Abra o endereço publicado no Safari.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início".
4. Confirme o nome e toque em Adicionar.

## Instalar no Android
1. Abra o endereço publicado no Chrome.
2. Abra o menu de três pontos.
3. Escolha "Instalar app" ou "Adicionar à tela inicial".
4. Confirme a instalação.

O nome exato das opções pode variar conforme navegador e versão do sistema.
